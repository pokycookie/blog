# 개발자 면접 준비: 기술면접 완벽 가이드

실제 면접 경험을 바탕으로 한 개발자 기술면접 준비 가이드입니다.

## 면접 프로세스 이해하기

### 일반적인 단계

1. **서류 전형**: 이력서, 포트폴리오
2. **코딩 테스트**: 알고리즘, 문제 해결
3. **기술 면접**: CS 지식, 프로젝트 경험
4. **컬처핏**: 팀 적합성, 가치관
5. **최종 면접**: 임원진 면접

## 기술 면접 준비

### CS 기초

#### 자료구조

```
필수 개념:
- Array vs Linked List
- Stack vs Queue
- Hash Table
- Tree (Binary Tree, BST)
- Graph
- Heap

예상 질문:
Q: Array와 Linked List의 차이는?
A: Array는 연속된 메모리 공간, O(1) 접근
   Linked List는 노드 연결, O(n) 접근
   삽입/삭제는 Linked List가 유리
```

#### 알고리즘

```
필수 개념:
- 정렬 알고리즘 (Quick, Merge, Heap)
- 탐색 알고리즘 (Binary Search, DFS, BFS)
- 동적 프로그래밍
- 그리디 알고리즘

예상 질문:
Q: Quick Sort의 시간 복잡도는?
A: 평균 O(n log n), 최악 O(n²)
   Pivot 선택이 중요
```

#### 운영체제

```
필수 개념:
- 프로세스 vs 스레드
- 동기화 (Mutex, Semaphore)
- 데드락
- 메모리 관리
- 가상 메모리

예상 질문:
Q: 프로세스와 스레드의 차이는?
A: 프로세스는 독립적인 메모리 공간
   스레드는 프로세스 내에서 메모리 공유
   컨텍스트 스위칭 비용이 스레드가 적음
```

#### 네트워크

```
필수 개념:
- OSI 7계층
- TCP vs UDP
- HTTP/HTTPS
- REST API
- CORS

예상 질문:
Q: TCP와 UDP의 차이는?
A: TCP는 연결 지향, 신뢰성 보장
   UDP는 비연결, 빠르지만 신뢰성 없음
   실시간 스트리밍은 UDP 사용
```

#### 데이터베이스

```
필수 개념:
- 정규화
- 인덱스
- 트랜잭션 (ACID)
- JOIN
- NoSQL vs SQL

예상 질문:
Q: 인덱스란 무엇이고 언제 사용하나?
A: 검색 속도 향상을 위한 자료구조
   WHERE, JOIN에 자주 사용되는 컬럼에 생성
   단, INSERT/UPDATE 성능 저하 가능
```

### 프론트엔드 특화

```javascript
// React
- Virtual DOM
- Hooks (useState, useEffect, useMemo)
- 상태 관리 (Redux, Zustand, Recoil)
- 렌더링 최적화

// JavaScript
- 클로저
- 프로토타입
- 이벤트 루프
- Promise, async/await

// 브라우저
- 렌더링 과정
- 이벤트 버블링/캡처링
- 웹 성능 최적화
- 웹 접근성

예상 질문:
Q: Virtual DOM이 무엇이고 왜 사용하나?
A: 실제 DOM의 가벼운 복사본
   변경사항을 Virtual DOM에서 비교 후
   필요한 부분만 실제 DOM에 반영
   성능 최적화에 유리
```

```javascript
A: 장점: Stateless, 확장성 좋음
   단점: 토큰 크기 큼, 무효화 어려움
   Refresh Token과 함께 사용 권장
```

## 프로젝트 경험 준비

### STAR 기법

```
Situation (상황)
- 어떤 프로젝트였나?
- 팀 구성은?

Task (과제)
- 내가 맡은 역할은?
- 해결해야 할 문제는?

Action (행동)
- 어떻게 접근했나?
- 어떤 기술을 사용했나?

Result (결과)
- 어떤 결과를 얻었나?
- 무엇을 배웠나?
```

### 예시

```
Q: 가장 어려웠던 기술적 문제는?

A:
Situation:
대용량 트래픽 처리 중 응답 속도 저하

Task:
API 응답 시간을 3초에서 1초 이하로 개선

Action:
1. 병목 지점 분석 (DB 쿼리)
2. 인덱스 추가 및 쿼리 최적화
3. Redis 캐싱 도입
4. 이미지 CDN 적용

Result:
- 응답 시간 70% 개선 (3s → 0.8s)
- 서버 부하 50% 감소
- 캐싱 전략 학습
```

### 답변 팁

```
✅ 좋은 답변:
- 구체적인 예시
- 수치로 증명
- 배운 점 강조

❌ 나쁜 답변:
- 추상적인 표현
- 부정적인 태도
- 준비 안 된 모습
```
