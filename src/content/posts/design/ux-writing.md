# UX Writing: 사용자를 움직이는 글쓰기

좋은 UX Writing이 제품의 사용성을 어떻게 개선하는지 알아봅니다.

## UX Writing이란?

사용자 인터페이스에서 사용자를 안내하고 도움을 주는 모든 텍스트를 말합니다.

### 포함되는 요소

- 버튼 텍스트
- 에러 메시지
- 온보딩 가이드
- 툴팁
- 알림 메시지
- 빈 상태 메시지

## 좋은 UX Writing의 원칙

### 1. 명확성 (Clarity)

```
❌ 나쁜 예: "처리 중입니다"
✅ 좋은 예: "결제를 처리하고 있습니다. 잠시만 기다려주세요."

❌ 나쁜 예: "오류가 발생했습니다"
✅ 좋은 예: "이메일 형식이 올바르지 않습니다. 다시 확인해주세요."
```

### 2. 간결성 (Conciseness)

```
❌ 나쁜 예: "지금 바로 회원가입을 진행하시면 다양한 혜택을 받으실 수 있습니다"
✅ 좋은 예: "회원가입하고 혜택 받기"

❌ 나쁜 예: "이 작업을 계속 진행하시겠습니까?"
✅ 좋은 예: "계속하시겠어요?"
```

### 3. 일관성 (Consistency)

```
✅ 좋은 예:
- "저장하기" (전체적으로 ~하기 사용)
- "삭제하기"
- "수정하기"

❌ 나쁜 예:
- "저장하기"
- "삭제" (일관성 없음)
- "수정"
```

### 4. 대화체 (Conversational)

```
❌ 나쁜 예: "입력하신 정보가 저장되었습니다"
✅ 좋은 예: "저장했어요!"

❌ 나쁜 예: "사용자 인증에 실패하였습니다"
✅ 좋은 예: "비밀번호가 일치하지 않아요"
```

## 실전 예시

### 에러 메시지

#### Before
```
Error 404: Resource not found
```

#### After
```
😕 페이지를 찾을 수 없어요

찾으시는 페이지가 삭제되었거나 주소가 변경되었을 수 있어요.
[홈으로 돌아가기]
```

### 빈 상태 (Empty State)

#### Before
```
데이터가 없습니다.
```

#### After
```
📝 아직 작성한 글이 없어요

첫 번째 글을 작성해보세요!
[글 쓰기]
```

### 버튼 텍스트

#### Before
```
[확인] [취소]
```

#### After
```
[삭제하기] [취소]
```

### 온보딩

#### Before
```
Step 1: 프로필 설정
이름과 이메일을 입력하세요.
```

#### After
```
👋 반가워요!

먼저 프로필을 설정해볼까요?
이름과 이메일만 입력하면 끝!

[1/3 단계]
```

### 로딩 상태

#### Before
```
Loading...
```

#### After
```
맛있는 레시피를 찾고 있어요 🔍
```

### 성공 메시지

#### Before
```
저장되었습니다.
```

#### After
```
✅ 저장 완료!

변경사항이 저장되었어요.
```

## 컨텍스트별 가이드

### 1. 폼 (Form)

```
Label: 명확하고 간단하게
✅ "이메일"
❌ "이메일 주소를 입력해주세요"

Placeholder: 예시 제공
✅ "example@email.com"
❌ "이메일"

Helper Text: 필요한 경우만
✅ "회사 이메일을 사용해주세요"

Error: 구체적인 해결 방법
✅ "비밀번호는 8자 이상이어야 해요"
❌ "유효하지 않은 비밀번호"
```

### 2. 버튼

```
동사로 시작
✅ "저장하기", "다운로드", "공유하기"
❌ "확인", "OK", "제출"

구체적으로
✅ "회원가입 완료하기"
❌ "다음"

긍정적으로
✅ "계속하기"
❌ "아니오"
```

### 3. 알림

```
중요도에 따라
Success: 긍정적, 격려
Warning: 주의 환기, 대안 제시
Error: 문제 설명, 해결 방법

예시:
✅ "업로드 완료! 친구들과 공유해보세요"
✅ "저장 공간이 부족해요. 불필요한 파일을 삭제해주세요"
✅ "연결이 끊어졌어요. 인터넷 연결을 확인해주세요"
```

## 톤 앤 보이스 (Tone & Voice)

### Voice (브랜드 개성)

일관되게 유지:
- 친근한 / 전문적인
- 캐주얼한 / 격식있는
- 유머러스한 / 진지한

### Tone (상황별 어조)

상황에 따라 조절:

```
성공: 축하하는, 격려하는
"잘하셨어요! 🎉"

에러: 공감하는, 도움주는
"앗, 문제가 생겼네요. 함께 해결해볼까요?"

경고: 주의를 주는, 명확한
"⚠️ 이 작업은 되돌릴 수 없어요"
```

## 다국어 고려사항

### 1. 문장 길이

```
영어: "Save"
한국어: "저장하기"
독일어: "Speichern"

→ 버튼 크기는 유연하게
```

### 2. 문화적 차이

```
이모지 사용 주의
👍 (서양: 긍정, 일부 국가: 모욕)

숫자 표기
1,000 vs 1.000
```

## 테스트하기

### A/B 테스트

```
A: "무료로 시작하기"
B: "지금 시작하기"

→ 클릭률, 전환율 측정
```

### 사용자 피드백

- 사용성 테스트
- 고객 지원 문의 분석
- 설문조사

## 체크리스트

- [ ] 명확한가? (이해하기 쉬운가)
- [ ] 간결한가? (불필요한 말이 없는가)
- [ ] 일관적인가? (다른 곳과 통일성이 있는가)
- [ ] 도움이 되는가? (사용자가 다음 행동을 알 수 있는가)
- [ ] 브랜드 톤에 맞는가?
- [ ] 접근성을 고려했는가?
- [ ] 다국어를 고려했는가?

## 실제 개선 사례

### 사례 1: 에러 메시지

**Before**
```
Error: Invalid input
```

**After**
```
이메일 형식이 올바르지 않아요
example@email.com 형식으로 입력해주세요
```

**결과**: 고객 문의 30% 감소

### 사례 2: CTA 버튼

**Before**
```
[제출]
```

**After**
```
[무료로 시작하기]
```

**결과**: 전환율 25% 증가

## 마치며

좋은 UX Writing은 사용자 경험의 핵심입니다. 작은 텍스트 하나가 사용자의 행동을 크게 바꿀 수 있습니다. 사용자의 입장에서 생각하고, 명확하고 친절하게 안내하세요! ✍️
