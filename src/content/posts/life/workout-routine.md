# 개발자를 위한 홈트레이닝 루틴

하루 종일 앉아서 일하는 개발자를 위한 실용적인 운동 루틴을 공유합니다.

## 왜 운동이 필요한가?

### 개발자의 고질병

- **거북목**: 모니터를 보는 자세
- **허리 통증**: 장시간 앉아있기
- **손목 터널 증후군**: 반복적인 타이핑
- **눈의 피로**: 화면 응시
- **체력 저하**: 운동 부족

### 운동의 효과

1. **신체적 효과**
   - 체력 향상
   - 자세 개선
   - 통증 완화
   - 면역력 강화

2. **정신적 효과**
   - 스트레스 해소
   - 집중력 향상
   - 수면 질 개선
   - 우울감 감소

3. **업무 효율**
   - 생산성 증가
   - 창의성 향상
   - 문제 해결 능력

## 홈트레이닝 루틴

### 준비물

```
필수:
- 요가 매트
- 편한 운동복

선택:
- 덤벨 (2-5kg)
- 저항 밴드
- 폼 롤러
```

### 주간 스케줄

```
월요일: 상체 + 코어
화요일: 하체
수요일: 휴식 (스트레칭)
목요일: 전신 운동
금요일: 상체 + 코어
토요일: 하체
일요일: 휴식
```

## 운동 루틴 (30분)

### 1. 워밍업 (5분)

```
1. 제자리 걷기 (2분)
   - 무릎을 높이 들어 올리기
   - 팔 크게 흔들기

2. 팔 돌리기 (1분)
   - 앞으로 10회
   - 뒤로 10회

3. 몸통 비틀기 (1분)
   - 좌우 각 10회

4. 다리 스윙 (1분)
   - 앞뒤로 각 10회
```

### 2. 상체 운동 (10분)

#### 푸쉬업 (팔굽혀펴기)

```
기본: 3세트 x 10-15회

변형:
- 쉬움: 무릎 대고
- 어려움: 다이아몬드 푸쉬업

주의:
- 몸은 일직선
- 팔꿈치는 45도
- 천천히 내려가기
```

#### 플랭크

```
기본: 3세트 x 30-60초

변형:
- 쉬움: 무릎 대고
- 어려움: 한 팔 들기

주의:
- 허리 꺾지 않기
- 엉덩이 들지 않기
- 호흡 유지
```

#### 덤벨 숄더 프레스

```
3세트 x 12-15회

없으면:
- 물병 사용
- 맨몸으로 동작만

주의:
- 허리 반동 금지
- 천천히 올리고 내리기
```

### 3. 하체 운동 (10분)

#### 스쿼트

```
기본: 3세트 x 15-20회

체크포인트:
- 발은 어깨 너비
- 무릎은 발끝 방향
- 엉덩이를 뒤로
- 허벅지가 바닥과 평행

변형:
- 쉬움: 의자 스쿼트
- 어려움: 점프 스쿼트
```

#### 런지

```
3세트 x 각 다리 10회

주의:
- 앞 무릎 90도
- 뒷 무릎은 바닥 가까이
- 상체 세우기

변형:
- 워킹 런지
- 사이드 런지
```

#### 힙 브릿지

```
3세트 x 15-20회

주의:
- 엉덩이 수축
- 허리 과도하게 젖히지 않기
- 천천히 내리기

변형:
- 한 다리 들기
- 발을 의자에 올리기
```

### 4. 코어 운동 (5분)

#### 크런치

```
3세트 x 15-20회

주의:
- 목에 힘 빼기
- 복부에 집중
- 천천히 올라가기
```

#### 레그 레이즈

```
3세트 x 10-15회

주의:
- 허리 바닥에 붙이기
- 다리 천천히 내리기
- 반동 금지
```

#### 플랭크 (사이드)

```
각 측면 3세트 x 30초

주의:
- 몸 일직선
- 엉덩이 떨어지지 않게
```

### 5. 쿨다운 (5분)

```
1. 팔 스트레칭
   - 삼두근: 30초씩
   - 어깨: 30초씩

2. 다리 스트레칭
   - 허벅지 앞: 30초씩
   - 허벅지 뒤: 30초씩
   - 종아리: 30초씩

3. 전신 스트레칭
   - 고양이 자세
   - 아기 자세
```

## 책상 앞 스트레칭 (5분)

### 1시간마다 하기

```
1. 목 스트레칭 (1분)
   - 좌우로 천천히
   - 앞뒤로 천천히
   - 원 그리기

2. 어깨 스트레칭 (1분)
   - 어깨 으쓱
   - 팔 돌리기
   - 어깨 뒤로 젖히기

3. 손목 스트레칭 (1분)
   - 손목 돌리기
   - 손가락 펴기
   - 손목 굽히기

4. 허리 스트레칭 (1분)
   - 의자에 앉아 비틀기
   - 앞으로 숙이기

5. 다리 스트레칭 (1분)
   - 발목 돌리기
   - 다리 펴기
```

## 영양 관리

### 기본 원칙

```
1. 단백질 충분히
   - 체중 x 1.5-2g
   - 닭가슴살, 계란, 두부

2. 탄수화물 적절히
   - 현미, 고구마, 귀리
   - 운동 전후 섭취

3. 지방 건강하게
   - 견과류, 아보카도
   - 올리브 오일

4. 물 많이
   - 하루 2L 이상
   - 운동 전후 필수
```

### 간단한 식단

```
아침:
- 오트밀 + 바나나 + 견과류
- 계란 2개
- 우유

점심:
- 현미밥
- 닭가슴살/생선
- 채소 샐러드

저녁:
- 고구마
- 두부/계란
- 채소

간식:
- 과일
- 견과류
- 프로틴 바
```

## 부상 예방

### 주의사항

```
1. 워밍업 필수
   - 근육 풀기
   - 부상 예방

2. 올바른 자세
   - 영상 참고
   - 거울 확인

3. 무리하지 않기
   - 통증 있으면 중단
   - 점진적 증가

4. 휴식 중요
   - 근육 회복 시간
   - 주 1-2일 휴식
```

### 통증 대처

```
근육통 (정상):
- 운동 후 24-48시간
- 따뜻한 물로 샤워
- 가벼운 스트레칭

관절통 (주의):
- 즉시 운동 중단
- 냉찜질
- 병원 방문

예방:
- 충분한 워밍업
- 올바른 자세
- 적절한 강도
```
